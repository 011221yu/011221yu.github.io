# 上岸工作台 · GitHub 版

网站程序公开，个人打卡、笔记、错题和导入题库保存在本机浏览器。

部署目录：`/shangan/`。独立目录不改动日常记录网站首页。目录内所有路径均为相对路径。

## 更新

修改 `shangan/` 下 HTML/JavaScript 后提交到 main。GitHub Pages 会自动重新部署。不要把用户的 JSON 备份、题库包、照片或密钥提交到仓库。

## 迁移

1. 原工作台 → 数据备份 → 下载备份文件。
2. 新工作台 → 数据备份 → 导入该文件。
3. 广东资料与刷题 → 导入 `shangan-materials.json.gz`，原题图和答案保存在 IndexedDB。
4. 每周导出学习档案。浏览器清除网站数据会同时清除题库，需要重新导入题库包。

日常记录网站与本工作台使用不同的浏览器存储键和服务缓存前缀，但同一 GitHub Pages 域名下的页面共享源；只应部署自己信任的代码。

注意：GitHub Pages 在不同地区的访问质量可能不同。核心页面、打卡、阅读及导入后的刷题不需要 ChatGPT 登录；PDF/OCR 模块需要相应识别资源加载成功。
